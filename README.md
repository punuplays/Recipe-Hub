# 🍽️ RecipeHub – Discover. Cook. Enjoy.

A modern and responsive recipe website featuring delicious recipes from different cuisines. Explore recipes, discover new dishes, and learn how to prepare them step by step.

## 🌟 Features

- 150+ detailed recipes
- 6 recipe categories
- Pizza recipes
- Burger recipes
- Pasta recipes
- Desserts
- Healthy food
- Indian food
- Recipe search functionality
- Detailed ingredients and cooking instructions
- Responsive website design
- Easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it using the Live Server extension.
5. Explore the recipes!
